# KEUM 3.1 — индивидуальные конструкции и проверяемость источников

## Назначение

Версия 3.1 заменяет часть шаблонных 412 представлений **индивидуальными геометрическими конструкциями**, вводит количественную оценку точности и обязательный журнал происхождения данных.

!!! warning "Статус"
    Это **интерпретативная геометрическая реализация**, а не восстановление точных физических законов эзотерических источников. Без контрольных точек, подписей и оригинальных схем точность нельзя подтвердить.

## Три уровня реализации

| Уровень | Критерий | Статус |
|---|---|---|
| L1 — типизированный экземпляр | ID, параметры, граф, экспорт | 412 концепций |
| L2 — индивидуальная конструкция | специфическая топология и числовые инварианты | 19 концепций |
| L3 — подтверждённая реконструкция | первоисточник, контрольные точки, количественная точность | 0 подтверждено |

**Kathara**:

$$

$$

**Двойная Меркаба**:

$$
|V|=8,\quad |E|=12,\quad
\theta_{\rm PCM}(t)=\theta_0+\omega t,\quad
\theta_{\rm PKA}(t)=-\theta_0-\omega t.
$$

$$

## Количественная верификация

`concept_engine/fidelity.py` реализует:

$$
\operatorname{RMSE}(P,Q)=
\sqrt{\frac1N\sum_{i=1}^N\|p_i-q_i\|^2},
$$

$$
d_{\rm Chamfer}(P,Q)=
\frac1{|P|}\sum_{p\in P}\min_{q\in Q}\|p-q\|^2+
\frac1{|Q|}\sum_{q\in Q}\min_{p\in P}\|q-p\|^2.
$$

Для графа:

$$
\beta_0=c,\qquad\beta_1=m-n+c.
$$

**Важно:** RMSE требует заранее сопоставленных точек в одной системе координат; Chamfer чувствителен к масштабу и плотности дискретизации. Эти показатели нельзя трактовать как объективную точность, если сканы не выровнены и не размечены.

## Журнал происхождения 412 записей

`concept_engine/provenance.py` создаёт `build/provenance_412.json`. Для каждого ID предусмотрены:

- `source_image_id`, `source_page`, `source_region`, `source_url`;
- `transcription_verified`, `geometry_verified`, `equations_verified`;
- `reference_points`, `model_points`;
- `reviewer`, `reviewed_at`, `mathematical_law_status`.

Неизвестные поля оставлены `null`, а статусы проверки — `false`. Это исключает ложные ссылки и выдуманные результаты измерений.

## Команды

```bash
python3 -m unittest discover -s concept_engine -p 'test_*.py'
python3 concept_engine/export_all.py --output vector_engine/graph_exports
python3 concept_engine/provenance.py --output build/provenance_412.json
```

Для геометрической проверки подготовьте JSON:

```json
{
  "reference_points": [[0, 0], [1, 0], [0, 1]],
  "model_points": [[0, 0], [1, 0], [0, 1]]
}
```

```bash
python3 concept_engine/fidelity.py measurements.json
```

Если эталонные точки не предоставлены, результат проверки будет `unverified`, а не вымышленная оценка точности.

## Следующая задача

Для перехода от L2 к L3 требуется разметка каждого из 49 оригинальных изображений: контрольные точки, оси, окружности, дуги, топология и подписи. После этого можно проводить метрологическую проверку каждой из 412 сущностей и создавать индивидуальные уравнения там, где они действительно определены.
