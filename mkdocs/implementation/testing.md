# Верификация, тесты и критерии приёмки

## Локальная проверка

```bash
python3 -m unittest discover -s vector_engine -p 'test_*.py'
python3 vector_engine/graph_engine.py --preset all --output /tmp/keum_exports
python3 -m pip install -r requirements-docs.txt
mkdocs build --strict
```

## Инварианты

| ID | Проверка | Ожидаемое |
|---|---|---|
| INV-01 | Уникальность ID | $|V|=|\mathrm{unique}(V)|$ |
| INV-02 | Ссылочная целостность | $\forall e=(u,v),\;u,v\in V$ |
| INV-03 | Конечность координат | $\forall x,\;|x|<\infty$ |
| INV-04 | Схема JSON | `keum.graph.v1` |
| INV-05 | XML | SVG успешно парсится |
| INV-06 | glTF | валидная структура буферов/аксессоров |
| INV-07 | Детерминизм | идентичные байты при одинаковых входах |
| INV-08 | Размерность | координаты имеют длину 3 |
| INV-09 | Поток (будущий солвер) | $\|\dot q-Bf-s\|\le\varepsilon$ |
| INV-10 | Фаза (будущий солвер) | $r(t)\in[0,1]$ |

## Геометрическая точность

Для каждой исходной схемы нужны: контрольные точки, восстановленные примитивы, масштаб, поворот, топологические признаки, RMSE и отметка ручной проверки. Пока этих измерений для всех 49 изображений нет.

## Контроль документации

`mkdocs build --strict` выявляет многие битые ссылки и предупреждения сборки. Проверку реального MathJax/MathML в браузере нужно проводить отдельно: наличие TeX-формулы в Markdown не гарантирует правильную отрисовку на всех устройствах.

## Статус

Тесты Python в репозитории проверяют графовый генератор; не следует считать, что ими проверена физическая теория или все 49 сканов.
