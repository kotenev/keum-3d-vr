# KEUM — математическая и архитектурная энциклопедия

**KEUM (Kathara–Eckasha Unified Model)** — исследовательский программный проект, объединяющий графовые модели, процедурную геометрию, SVG, glTF, Three.js и WebXR. Исходный корпус — 59 файловых позиций (58 уникальных изображений) и рабочий реестр 493 терминов.

!!! warning "Эпистемический статус"
    KEUM — **символическая математическая реконструкция** эзотерических схем, а не подтверждённая физическая теория. Термины «энергия», «поле», «измерение», «ДНК» в описаниях оригинальных учений не означают, что соответствующие сущности измерены или признаны наукой.

## Энциклопедия 493 понятий

Добавлены **14 исходных тематических глав и дополнительная глава для 10 новых изображений** с индивидуальными карточками 412 исходных сущностей; ещё 81 понятие добавлено по десяти новым изображениям: исходное название и описание, разбор термина, формальная интерпретация, эвристические связи, указатель изображения и статус верификации. [Начать с космологии](encyclopedia/cosmology.md) или выбрать раздел в навигации.

**Ограничение:** большинство исходных описаний в JSON-каталоге шаблонные. Энциклопедия разворачивает их в структурированные исследовательские карточки, но не заменяет критическое чтение 49 первоисточников.

## Математическая постановка

Модель описывается кортежем

$$
\mathcal U=(V,E,\Lambda,X,Z,\Theta,\mathcal T,\mathcal O),
$$

где $V$ — узлы, $E$ — связи, $\Lambda$ — метки уровней, $X$ — координаты, $Z$ — комплексные состояния, $\Theta$ — фазы, $\mathcal T$ — операторы эволюции, $\mathcal O$ — наблюдаемые выходы визуализации.

Формулы в этом сайте записаны в **LaTeX** и отображаются MathJax (с поддержкой вывода MathML средствами движка). Они не являются доказательством исходных метафизических утверждений.

## Быстрый запуск

```bash
git clone https://github.com/kotenev/keum-3d-vr.git
cd keum-3d-vr
python3 -m pip install -r requirements-docs.txt
mkdocs serve
```

Документация: `http://127.0.0.1:8000`. Для запуска 3D-атласа используйте `python3 serve.py` отдельно, на другом порту при необходимости.
