# Методология и границы интерпретации

## Четыре уровня утверждений

1. **Источник (S):** утверждение, встречающееся на диаграмме или в авторском материале.
2. **Реконструкция (R):** формальное определение, выбранное разработчиком KEUM.
3. **Реализация (I):** конкретный алгоритм, присутствующий в исходном коде.
4. **Гипотеза (H):** расширение, требующее проектирования, реализации или экспериментальной проверки.

Нельзя выводить истинность S из математической согласованности R или корректности I.

## Критерии качества

| Метрика | Определение | Метод проверки |
|---|---|---|
| Coverage | доля понятий, связанных с модельными сущностями | каталог ID |
| Traceability | доля сущностей с исходной схемой/страницей | таблица соответствий |
| Geometric fidelity | расстояние между эталонными и восстановленными примитивами | RMS/Chamfer |
| Topological fidelity | совпадение узлов, рёбер и циклов | graph edit distance |
| Reproducibility | одинаковый результат при одинаковом seed | сравнение хэшей |
| Numerical stability | ограниченность ошибки интегратора | тесты сходимости |
| Semantic confidence | уверенность в расшифровке оригинальной подписи | экспертная проверка |

## Неопределённость

Для каждой реконструируемой сущности рекомендуется хранить `source_image`, `page`, `confidence`, `interpretation_status`, `author_term`, `model_assumption`. Отсутствующие значения не подменяются догадками.

## Статус «теорий»

Историческая Каббала и современные Freedom Teachings — различные традиции. Сходство визуальных метафор не устанавливает историческую преемственность. Физические термины в эзотерических схемах рассматриваются как авторский язык, если нет независимых измерений и проверяемых уравнений.

## Условия научной проверяемости

Для эмпирического утверждения нужны операциональное определение, измерительная процедура, прогноз, контроль ошибок и возможность опровержения. Сами SVG/VR-сцены этим условиям не удовлетворяют.
